# 255441 Midterm Exam - Codes

This repository contains midterm exam submissions for course 255441.
Each student folder is organized by student ID and grouped into three projects.

## Repository Structure

- `src/project_1/` HTML + CSS static pages
- `src/project_2/` HTML + CSS + JavaScript pages
- `src/project_3/` Vue.js projects (one app per student ID)

## Prerequisites

For Project 1 and Project 2:

- A modern web browser
- VS Code with Live Server extension (recommended)

For Project 3:

- Node.js (LTS version recommended)
- pnpm package manager

## How to Run

### Project 1

1. Open a student folder in `src/project_1/<student_id>/`.
2. Open `index.html`.
3. Run with Live Server:
   - Right-click `index.html`
   - Select Open with Live Server

### Project 2

1. Open a student folder in `src/project_2/<student_id>/`.
2. Open `index.html` (or other entry pages if provided).
3. Run with Live Server the same way as Project 1.

### Project 3 (Vue.js)

Run each student project independently.

Example for `src/project_3/660615046`:

1. Open a terminal at the repository root.
2. Run:

   ```bash
   cd src/project_3/660615046
   pnpm install
   pnpm run dev
   ```

3. Open the local URL shown in terminal (commonly `http://localhost:5173/`).
